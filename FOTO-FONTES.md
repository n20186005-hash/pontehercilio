# Fontes verificadas de fotografias reais

O site foi preparado para usar JPGs locais em `public/images/`, sem hotlink. Neste pacote de rascunho, os binários não foram materializados porque o ambiente de execução não permite transferir os arquivos pesquisados na web para o sistema de arquivos local. Nenhum desenho ou imagem sintética foi mascarado como foto real.
