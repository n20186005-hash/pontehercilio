# Guia Ponte Hercílio Luz

Site independente em português do Brasil, construído com Astro estático e Tailwind. A previsão existente é consultada no navegador diretamente em Open-Meteo.

Use a versão de Node e pnpm declarada em package.json. Instale com `pnpm install --frozen-lockfile`, valide com `npm run check` e gere os arquivos com `npm run build`. O comando padrão `npx wrangler deploy` usa src/worker.js e os assets de dist, incluindo a normalização de domínio/protocolo e respostas de erro.

As fontes institucionais estão nas páginas do guia. Créditos e licenças por fotografia: /creditos/. Configurações de análise: /cookies/.
